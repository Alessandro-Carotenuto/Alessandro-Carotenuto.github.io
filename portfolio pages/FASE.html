Overview

A symbolic robotics toolbox built in Python using SymPy, designed to model, analyse, and control robotic systems using exact symbolic mathematics rather than numerical approximations. It supports both serial manipulators and autonomous mobile robots.

Given a joint string (e.g. "RRR" for a 3-DOF revolute arm), the toolbox automatically computes forward kinematics, the geometric Jacobian, and the full Lagrangian dynamics — inertia matrix $M(q)$, Coriolis vector $c(q, \dot{q})$, and gravity vector $G(q)$ — all in closed symbolic form.

Key Elements

Forward Kinematics

Automatic computation of the full homogeneous transform chain via Denavit–Hartenberg parameters.

$$T_n^0 = \prod_{i=1}^{n} A_i(q_i)$$

Geometric Jacobian

Symbolic derivation of the full Jacobian, split into linear $J_v$ and angular $J_\omega$ components.

$$J(q) = \begin{bmatrix} J_v \\ J_\omega \end{bmatrix}$$

Lagrangian Dynamics

Full symbolic derivation of the robot's equations of motion from kinetic and potential energy.

$$\tau = M(q)\ddot{q} + c(q,\dot{q}) + G(q)$$

Mobile Robotics

AMR module with planned support for differential drive, omnidirectional, and Ackermann kinematic models, path planning, and SLAM.
