Overview

This project reconstructs the principal components of CTA-Net, introduced by Fu et al. (2025), a CNN-Transformer and channel-spatial attention approach for hyperspectral image classification with few labeled samples. It predicts the land-cover class at the center of each image patch, using Pavia University as the main experiment.

A multiscale CNN captures local spatial patterns while a Conformer-style Transformer branch models broader relationships. Their features are fused with a residual connection, then refined by channel and spatial attention. A training-only sample amplification pipeline combines original patches with noise-based, rotated and same-class direct-sum variants.

In the transformer-head ablation, the 8-head configuration achieved 88.42% overall accuracy, 90.07% average accuracy and 84.96% Cohen's Kappa, averaged over 10 training seeds on the fixed split (seed 42). Compared with the 4-head baseline, this is a gain of 2.87 percentage points in OA, 1.07 points in AA and 3.48 points in Kappa.

Key Elements

Few-shot protocol

Only 10 training and 5 validation pixels per class; remaining labeled pixels form the test set.

CNN + Transformer

Parallel multiscale convolution and Transformer branches combine local spatial features with wider context.

Channel-spatial attention

Sequential channel and spatial attention recalibrate features before producing the center-pixel class scores.

Reproducible evaluation

Fixed split, controlled training seeds, per-class metrics, confusion matrices and saved run configurations support analysis.
