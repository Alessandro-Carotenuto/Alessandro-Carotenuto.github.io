Overview

This C++ project implements forward and inverse kinematics for a revolute-revolute-prismatic robot arm. A numerical Jacobian and its SVD-based pseudoinverse drive an iterative solver that updates joint coordinates to reduce Cartesian end-effector position error.

The same algorithms work with two model representations through a shared KinematicModel interface. DHModel loads Denavit-Hartenberg parameters directly or from YAML; URDFModel parses a robot description with urdfdom, extracts the selected base-to-tool chain, and handles revolute, prismatic and fixed joints. The project implements FK, Jacobian and IK itself rather than delegating those calculations to KDL.

The current IK solves Cartesian position only; end-effector orientation is outside the present solver scope. ROS 2 integration is part of the project roadmap.

Key Elements

One model interface

KinematicModel lets the same Jacobian and IK algorithms operate on either DH or URDF robot descriptions.

URDF chain extraction

Loads a chosen base-to-tool chain and applies each joint origin and motion for forward kinematics.

Numerical IK

A finite-difference Jacobian and SVD pseudoinverse iteratively reduce position error at the end-effector.

Model-level verification

Tests cover model loading, forward kinematics, Jacobians, IK and equivalence of the visual and kinematic URDF models.
